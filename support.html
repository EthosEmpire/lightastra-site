What you can ask for

Update, fix, improve, secure, maintain.

Most support requests fall into one of five kinds. Pick the closest request type on the form; the description does the rest.

  • Update

    Text, images, prices, opening hours, a new section — content changes to a site I built.

  • Fix

    Something broken or misbehaving: a form, a layout, a link, a page that stopped working.

  • Improve

    A new feature or a design change on an existing project. Larger work receives its own quote first.

  • Secure

    A security concern, a configuration check, an access change — verified with you before anything changes.

  • Maintain

    Routine care, hosting and domain questions, renewals, backups and software updates.

Identification

Your Client ID and Project ID

Every completed Light Astra project receives a Client ID (LA-C1027, for example) and a Project ID (LA-P2048). Quoting them on a request helps me locate the correct project quickly.

Where to find them
You received your Client ID and Project ID when your Light Astra project was completed.
Lost them?
You can still contact Light Astra using your registered project email: send the request without the IDs and I will find the project.
What they are not
Identifiers, not passwords. An ID is not a login, entering one does not verify who you are, and it unlocks no private information.

Requests are matched to the registered project email. When the Light Astra support system is activated, it will verify client accounts properly and assign ticket numbers; until then, the IDs only point me to the right project.

Good to know

            
How support works

          

          
Plain operating guidance, not contract terms — the Terms of Service cover the agreement itself.

        

        

          

            
Care plans

            
Small updates may be covered by an active maintenance plan (Astra Care or Astra Plus). Plans cover routine care, not unlimited work.

          

          

            
Larger changes

            
New features, redesigns and bigger changes are scoped and quoted separately before any paid work begins.

          

          

            
Security and infrastructure

            
Security, hosting, domain and access work may require verification with the registered client before changes are made.

          

          

            
Secrets

            
Never send passwords, API secrets, private keys, SSH keys, recovery codes or payment credentials through the support form or email. A secure hand-over is arranged when access is genuinely needed.
